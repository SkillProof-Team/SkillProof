## 复现

在安装了测试依赖的 Python 3.13.9 环境、仓库根目录执行（macOS / Linux）：

```sh
export PYTHONPATH=backend
export PYTHONDONTWRITEBYTECODE=1
export SKILLPROOF_ENV=development
python -m unittest discover -s backend/tests -v
python -m unittest discover -s tests/acceptance -v
```

用例自行创建临时数据库。完整输出保存在[运行日志](evidence/20261108-backend-acceptance.txt)，其中测试环境的绝对路径已替换为 `<test-environment>`。
