## 环境及命令

Windows、Python 3.12.14，独立虚拟环境，运行依赖按团队 `backend/requirements.txt` 安装；HTTP 测试依赖为 `httpx==0.28.1`。使用 Python 自带 unittest 和 FastAPI TestClient。

在仓库根目录执行：

```powershell
python -m pip install -r backend/requirements-dev.txt
python -B -m unittest discover -s backend/tests -p 'test_*.py' -v
```
