# V0.1 预发布

日期：2026-11-14（北京时间）。本版用于先行下载和本机演示，GitHub 标记为 Pre-release，Tag 为 `V0.1`，目标为 `deploy/13-alpha-release` 的交付提交。构建包 manifest 记录精确源码提交；应用逻辑与已验收基线 `1ad8cb0d5214ad79266a80d8e5c79fa83bb00b9f` 一致。

## 本版内容

- 真实注册登录、后端岗位选择、18 题测评、保存恢复、提交评分与六维结果页。
- SQLite 持久化，题库版本同步；默认 42 道已发布题。
- 更新后的安装说明、部署记录、回归报告、截图证据与正式发布清单。
- Release 附件提供前端编译 dist、后端 Python 源码及固定依赖清单、manifest 和 SHA256。编译产物不进入 Git 或 main。

## 运行

解压 `SkillProof-V0.1.zip`，进入包内 SkillProof-V0.1 目录，按 [README](../../README.md) 安装 Python 3.13.9、Node 24.12.0/npm 11.6.2 所需依赖，复制 .env.example。已带 dist，可以跳过前端重新构建；启动 API 和 Vite preview，访问 http://127.0.0.1:4173。后端无独立 exe，包内不含 Python、Node、依赖目录、账号、.env 或数据库。

## 验证与限制

基线本轮 115 项后端测试、前端 lint/build 通过；Chrome 完成真实流程、保存刷新和两次正常 API 重启恢复，另验证过解压编译包。具体证据及未执行项见 [部署回归报告](../testing/alpha-deployment-report.md)。新增交付提交只更新文档、配置模板和必测登记，不改应用逻辑或依赖锁。
