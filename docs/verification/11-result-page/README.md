## 当前契约与联调结论

- 综合分直接展示服务端按题目难度 `1 / 2 / 5` 加权计算的 `score`，前端不进行岗位权重重算
- 六个维度必须同时包含 `score`、`correct` 和 `total`，并校验总答对数、题目数和维度合计一致
- 薄弱项直接使用服务端 `weakDimensions` 顺序，不再读取未被后端实现的 `weight`、`priority`、`limitations` 等字段
- 本地临时集成分支组合 #19、#25、#11 与团队 `local/8-scoring-integration` 后，前端 lint、build 通过，后端 73 项测试全部通过
- 真实 HTTP 流程已验证注册、岗位查询、创建 18 题测评、保存全部答案、提交评分及本人报告查询；返回 6 个维度，维度合计与总题数、总答对数一致
- 权限分支已验证：本人查询报告为 200，未登录为 401，其他账号查询为 404；真实 Cookie 登录后，桌面 1280px 结果页无错误或横向溢出
- #30、#28、#27、#19、#25 仍未全部合并，上述结果属于基于团队最新临时集成分支的提前验收，不替代最终 `main` 回归
